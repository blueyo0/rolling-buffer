审稿工作台

审稿在 GitHub 进行。使用有权限的 GitHub 账号登录，才能看到私有稿件和评审记录。

打开私有审稿

查看待审 PR →选题与审稿单查看发布记录

  1. 在 PR 的 Files changed 中核对最终正文，可逐行留意见。
  2. 在文章开头设置 highlight: true 加入首页精选，或设为 highlight: false 只保留在归档。
  3. 确认后由站主亲手合并。发布流程只处理符合格式的文章文件；评论、未合并的 PR 和其他私有文件不会发布。

In the Buffer

首页最多显示四篇标为精选的文章，按文章日期由新到旧排列。要换下已发布的精选，在私有 PR 中把该文章的 highlight 改为 false。这不会删除文章，也不会改变原来的链接。
